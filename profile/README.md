Apollo is a high-contrast color system with **Dark and Light** appearances carried across 17 applications. Existing unsuffixed `Apollo` names remain Apollo Dark compatibility identities; Light is always named **Apollo Light**. Every port is independently installable, tested in its native format, and synchronized from canonical palettes.

## One source, many ports

The exact colors, provenance, and synchronized repository map live in [`apollo-theme/apollo-theme`](https://github.com/apollo-theme/apollo-theme). Browse the visual simulations at [`apollo-theme.github.io`](https://apollo-theme.github.io/) before installing a port.

## Lineage

Apollo stands on excellent prior art. Thank you to [Gruvbox](https://github.com/morhetz/gruvbox) for its enduring dark and light color language and [SonicTerm](https://github.com/D0n9X1n/SonicTerm) for the high-contrast terminal palette that became Apollo’s dark starting point.
