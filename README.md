Apollo is a higher-contrast take on Gruvbox Dark Hard: a near-black canvas, warm text, a yellow focus accent, and a bright Base16 terminal palette. One canonical palette powers every integration, so your environment stays unmistakably yours from terminal to editor.

## ✧ Start here

1. Choose your tool from the list above.
2. Follow its installation instructions.
